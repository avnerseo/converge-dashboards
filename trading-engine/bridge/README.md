# הגשר — ערוץ בין הסשן בענן לסשן המקומי

הסשן בענן **אינו רואה** את המסך, את המחשב, או את הריפו הפרטי של המנוע.
הוא רואה רק את הריפו הזה. הסשן המקומי אינו רואה את שיחת הענן.

**הגשר היחיד בין שניהם הוא התיקייה הזו.**

## איך זה עובד

```
הענן   → כותב ל-  bridge/from-cloud/  → המקומי מושך וקורא
המקומי → כותב ל-  bridge/from-local/  → הענן מושך וקורא
```

## כללים

1. **שם קובץ מתוארך:** `YYYY-MM-DD-נושא.md`. לא דורסים קבצים קיימים —
   מוסיפים חדש. ההיסטוריה היא חלק מהראיה.
2. **דוחות הולכים לכאן, לא לצ'אט.** הדבקה נחתכת. השבוע אבד כך מידע
   שחסם החלטה.
3. **דוחפים בסוף כל שלב משמעותי**, לא בסוף היום.
4. **הקוד לא עובר לכאן.** רק דוחות, ממצאים, החלטות ושאלות.
5. מסקנות שמשנות את מצב הפרויקט עוברות גם ל-`trading-engine/STATE.md`.
