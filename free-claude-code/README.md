# Free Claude Code — התקנה מבודדת

מימוש של מה שהוצג בריל: הפעלת ה-CLI של Claude Code מול פרוקסי מקומי שמנתב את הבקשות
לספק מודלים אחר, במקום ל-Anthropic.

הפרויקט עצמו: [Alishahryar1/free-claude-code](https://github.com/Alishahryar1/free-claude-code) —
פרויקט קוד פתוח עצמאי, **לא קשור ל-Anthropic ולא מאושר על ידה**.

---

## מה זה באמת עושה (חשוב לקרוא לפני)

זה **לא** נותן לך את המודלים של Claude בחינם. זה נותן לך את **הממשק** של Claude Code —
הטרמינל, הכלים, ה-agent loop — כשמאחוריו רץ מודל אחר לגמרי (GLM, Kimi, Qwen, Llama וכו').

מה שמשתנה בפועל:

| | Claude Code רגיל | דרך הפרוקסי |
|---|---|---|
| המודל | Claude | מודל צד ג׳ (משתנה לפי הספק) |
| עלות | מנוי / API | חינם או כמעט חינם |
| איכות בעבודה ארוכה עם קבצים גדולים | גבוהה | נמוכה משמעותית |
| הקוד והפרומפטים שלך | לפי מדיניות Anthropic | עוברים דרך הספק שבחרת |

החינמיים, נשארים בחשבון ככסף אמיתי לשימוש במודלים חזקים כשצריך, ו**מאפשרים לך לבטל ניתוב
לספקים שמאמנים על הנתונים שלך** — בדיוק מה שאין ב-NVIDIA.

NVIDIA NIM נותנת מכסה גדולה יותר בחינם, אבל התמורה היא שהקוד והפרומפטים שלך הופכים
לחומר אימון. לדשבורדים האלה — מתודולוגיה, לוגיקת דירוג, רשימות אחזקות — זה מחיר אמיתי,

מקומי הוא היחיד שהוא באמת "חינם לנצח" ופרטי לחלוטין, אבל מודל שרץ על מחשב אישי לא מתקרב
לאיכות שצריך לעריכת קבצי HTML בני אלפי שורות.

## התקנה

הסקריפטים כאן **לא נוגעים בהתקנת Claude Code הקיימת שלך**. הכול נכנס לתיקייה אחת
(`~/.free-claude-code`), וה-Claude Code שרץ מול הפרוקסי מקבל `CLAUDE_CONFIG_DIR` נפרד —
כלומר החשבון והמנוי שלך נשארים כפי שהם, וההסרה היא מחיקת תיקייה אחת.

> שים לב: הסקריפט הרשמי של הפרויקט (`curl ... | sh`) מתקין תריסר CLIs נוספים
> (Codex, Grok, OpenCode, Aider ועוד), משנה PATH, ומריץ `rtk init --global --auto-patch`
> שנוגע ב-`~/.claude` הקיים שלך. הסקריפטים כאן עושים רק את מה שצריך.

### שלב 1 — דרישות מוקדמות

צריך `git`, ה-CLI של Claude Code, ומנהל החבילות `uv`.

**macOS / Linux / WSL:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh     # או: brew install uv
```

**Windows:**
```powershell
winget install --id astral-sh.uv                    # או: irm https://astral.sh/uv/install.ps1 | iex
```

### שלב 2 — מפתח API

ב-[openrouter.ai/keys](https://openrouter.ai/keys) → צור מפתח. אם בחרת בהמלצה, הפקד $10
ואז ב-Settings → Privacy בטל ניתוב לספקים שמאמנים על נתונים.

(לחלופין NVIDIA: [build.nvidia.com](https://build.nvidia.com) → Get API Key.)

### שלב 3 — הרצה

**macOS / Linux / WSL:**
```bash
cd free-claude-code
chmod +x fcc.sh
./fcc.sh setup      # שיבוט הפרויקט + התקנת תלויות + הזנת המפתח
./fcc.sh start      # הפעלת הפרוקסי על פורט 8082
./fcc.sh claude     # פתיחת Claude Code מול הפרוקסי
```

**Windows PowerShell:**
```powershell
cd free-claude-code
Set-ExecutionPolicy -Scope Process Bypass -Force
.\fcc.ps1 setup
.\fcc.ps1 start
.\fcc.ps1 claude
```

אחרי `start` נפתח ממשק ניהול ב-<http://127.0.0.1:8082> — שם בוחרים איזה מודל ישמש
לכל דרג (Opus/Sonnet/Haiku ממופים למודלים של הספק).

### אם משהו נתקע — לקחים מהתקנה אמיתית על Windows

ארבעה מכשולים עלו בהתקנה הראשונה. הסקריפטים כבר מטפלים בכולם, אבל כדאי להכיר אותם.

**המפתח נדחה עם 401 למרות שהוא תקין.** הסיבה הנפוצה: מעתיקים מקוד הדוגמה של הספק את השורה
השלמה — `"Bearer nvapi-..."` — כולל המילה `Bearer` והגרשיים. שדה הקלט מוסתר, אז אי אפשר
לראות את זה. ההתקנה מנקה את זה אוטומטית ומודיעה כשהיא עושה זאת. לאבחון: `fcc.ps1 testkey`
פונה לספק ישירות, בלי הפרוקסי, ואומר אם הבעיה במפתח או בהגדרה.

**המפתח הוחלף אבל השרת ממשיך לדחות.** האפליקציה קוראת את ההגדרות מ-`~/.fcc/.env` בלבד —
הנתיב שמופיע בתחתית כל מסך בממשק הניהול. הסקריפטים כותבים לשם. אם ערכת ידנית קובץ אחר,
הוא פשוט לא נקרא. חשוב גם: **אחרי כל שינוי מפתח צריך להפעיל את השרת מחדש**, כי הוא מחזיק
את הערך בזיכרון.

**`Application Control policy has blocked this file` (שגיאה 4551).** Windows חוסם את קובץ
ההרצה ש-uv מייצר, כי הוא לא חתום דיגיטלית. הסקריפטים מריצים את השרת דרך `python` במקום,
ולכן אין מה לחסום. **אל תכבה את Smart App Control** בשביל זה — זה מתג שקשה מאוד להחזיר.

**`stop` לא מוצא את השרת.** אם קובץ ה-PID אבד, השרת ממשיך לרוץ ו-`start` יגיד
`already listening`. הריגה לפי הפורט:
```powershell
Get-NetTCPConnection -LocalPort 8082 -State Listen | % { Stop-Process $_.OwningProcess -Force }
```

**טיפ אחרון:** ב-Windows Terminal הדבקה נוטה להיכפל, והפקודה נשלחת פעמיים ברצף
(`git statusgit status`). לפני כל אנטר — מבט מהיר על השורה.

## נגמרה המכסה של המנוי? שלושה מצבים מאותו מקום

| הרצה | מה רץ מאחורה | חיוב |
|---|---|---|
| `claude` (רגיל) | Claude, דרך המנוי | נספר במכסת המנוי |
| `./fcc.sh api` | Claude, דרך ה-API | **לפי טוקנים, לא נוגע במכסת המנוי** |
| `./fcc.sh claude` | מודל צד ג׳ דרך הפרוקסי | חינם / כמעט חינם |

`api` מריץ את Claude Code ישירות מול Anthropic — בלי הפרוקסי, עם `ANTHROPIC_API_KEY` שלך,
בפרופיל נפרד משלו. זו הדרך להמשיך לעבוד באותה איכות כשהמנוי נגמר.

המפתח נלקח לפי הסדר: משתנה סביבה קיים ← קובץ שמור ב-`~/.free-claude-code/api-key`
(הרשאות 600) ← שאלה בהרצה, עם אפשרות לשמור. יצירת מפתח:
[console.anthropic.com](https://console.anthropic.com/settings/keys).

תמחור נכון להיום, לכל מיליון טוקנים: **Opus 5** — $5 קלט / $25 פלט;
**Sonnet 5** — $2 / $10; **Haiku 4.5** — $1 / $5. ההוצאה בפועל מוצגת ב-Console.

> **מתי כדאי מה:** לעדכון היומי של הדשבורדים — `api`. עריכות ממוקדות בקבצי HTML ענקיים
> הן בדיוק מה שמודלים חינמיים שוברים, ושעה של תיקון שווה יותר מכמה דולרים של API.
> את הפרוקסי שמור למשימות זולות ומבודדות.

## מגבלות שכדאי לדעת מראש

- **מכסות**: 20 בקשות/דקה ב-OpenRouter. Claude Code שולח הרבה בקשות ברצף, אז במשימות
  ארוכות תיתקל בהאטות. זו לא תקלה בהתקנה.
- **איכות בעבודה על הדשבורדים**: העדכון היומי כאן כולל עריכות ממוקדות בקבצי HTML ענקיים
  ושימוש ב-MCP. מודלים חינמיים נוטים לשבור עריכות כאלה. מומלץ להמשיך להריץ את העדכון
  היומי עם Claude Code הרגיל, ולהשתמש בפרוקסי למשימות זולות ומבודדות.
- **תאימות**: זהו פרויקט צד ג׳ שמתרגם בין ה-API של Anthropic לספקים אחרים. עדכון של
  Claude Code או של הספק עלול לשבור אותו זמנית.
- **תנאי שימוש**: אתה אחראי לעמידה בתנאים של הספק שבחרת. ההרצה מול ספק חיצוני אינה
  שימוש במנוי Anthropic שלך ואינה נספרת בו.
