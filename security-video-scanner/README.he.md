# vscan — חיפוש בתוך הקלטות של מצלמות אבטחה

> English documentation: [README.md](README.md)

הכלי מקבל תיקייה של הקלטות ועונה על השאלה *מתי* משהו קרה:

```bash
vscan index recordings/ -r --objects              # סריקה ואינדוקס של ההקלטות
vscan enroll --name "דוד" photos/david*.jpg       # מלמדים אותו איך דוד נראה
vscan find  --person "דוד" --arrivals --report david.html   # מתי דוד הגיע
vscan ask   "מישהו נושא קרטון גדול לכיוון הכניסה" --report box.html
```

## שלושה מנועי חיפוש, אינדקס אחד

| חיפוש | על מה עונה | איפה רץ |
|---|---|---|
| **פנים** (`find`) | מתי אדם מסוים מופיע, ובאיזו דקה הגיע | מקומי לגמרי (YuNet + SFace) |
| **אובייקטים** (`objects`) | מתי היה מישהו בכלל, רכב, תיק, כלב… (80 מחלקות) | מקומי לגמרי (YOLOX‑S) |
| **הוראה חופשית** (`ask`) | כל דבר שאפשר לתאר במשפט | הפריימים נשלחים ל‑Claude API |

כל מה שאינו `ask` עובד לחלוטין אופליין — שום פריים לא יוצא מהמחשב.

## התקנה

```bash
sudo apt install ffmpeg        # או brew install ffmpeg
pip install -e .
pip install anthropic          # רק אם רוצים את הפקודה ask
vscan models fetch             # כ‑75MB מודלים, פעם אחת למחשב
```

צריך Python 3.10 ומעלה. לא צריך כרטיס מסך — הכול רץ על CPU.

## איך עובדים

### 1. אינדוקס

```bash
vscan index /media/dvr/2026-08-30/ -r --fps 2 --objects
```

ffmpeg מפענח את הווידאו (כל פורמט שמצלמת אבטחה מייצרת), הכלי דוגם פריימים
(ברירת מחדל 2 בשנייה) ומעביר כל אחד דרך **מסנן תנועה** — ברוב הפריימים
בהקלטת אבטחה שום דבר לא זז, ודילוג עליהם הוא מה שהופך שעות של חומר לבר‑ביצוע.
הפריימים ששרדו נשמרים עם הפנים שזוהו בהם (תיבה + וקטור 128 מימדים),
אובייקטים, ותמונה ממוזערת — הכול בתיקייה `./vscan-index/`.

שעון אמת נלקח מתגית הזמן של הקובץ, משם הקובץ בסגנון DVR
(`ch01_20260830140000.mp4`), או מ‑`--start-time "2026-08-30 14:00"`. משם והלאה
התוצאות מציגות שעה אמיתית ולא רק היסט מתחילת ההקלטה.

### 2. להגיד את מי מחפשים

שלוש דרכים שוות ערך:

```bash
# א. מתוך תמונות
vscan enroll --name "דוד" david1.jpg david2.jpg

# ב. מתוך רגע בהקלטה עצמה ("הנה הוא, בדקה הזאת")
vscan enroll --name "דוד" --from-video gate.mp4 --at 00:03:12 --at 00:07:40

# ג. בלי להכיר אף אחד מראש: לקבץ את כל הפנים ואז לתת שם
vscan cluster --report faces.html
vscan label --cluster 0 --name "שליח"
```

`vscan cluster` עונה על "מי בכלל מופיע בהקלטות האלה": הוא מקבץ את כל הפנים
לאשכול אחד לכל אדם, ומייצר דף HTML עם תמונה מכל אשכול.

### 3. חיפוש

```bash
vscan find --person "דוד"                        # כל ההופעות
vscan find --person "דוד" --arrivals             # רק ההגעות
vscan find --person "דוד" --from 20:00 --to 23:00 --clips ./clips
vscan objects --labels person car --arrivals     # "מישהו היה כאן" בלי זיהוי פנים
vscan ask "רכב מסחרי שעוצר בשער"                 # כל תיאור חופשי
```

הפלט:

```
  1. gate_cam.mp4  00:12:03 - 00:12:24  (21.0s, 42 hits, best 00:12:11 @ 0.611)  [2026-08-30 14:12:03]
```

`--gap` קובע מתי שתי זיהויים עוקבים מפסיקים להיות אותה הופעה (ברירת מחדל 5
שניות). `--arrivals` מכווץ עוד: רק ההופעה הראשונה אחרי `--absence` שניות
(ברירת מחדל 5 דקות) של היעדרות — זו בדיוק השאלה "מתי הוא הגיע לבניין".

`--clips DIR` חותך קטע וידאו לכל אירוע, `--report FILE` מייצר דף HTML עצמאי
(התמונות מוטמעות בקובץ, אפשר לשלוח אותו במייל), `--json FILE` מייצר פלט
לעיבוד תוכנה.

## `ask` — חיפוש לפי הוראה

```bash
export ANTHROPIC_API_KEY=sk-ant-...
vscan ask "מישהו משאיר תיק ליד הכניסה והולך" --from 18:00 --to 23:59 --report bag.html
```

שני שלבים: קודם **מיון** — הפריימים מסודרים בגיליונות ממוספרים (9 בבקשה)
ונשלחים ל‑Claude עם ההוראה שלך, והוא מחזיר אילו מהם מתאימים ובאיזה ביטחון;
אחר כך **אימות** — כל מועמד נבדק שוב לבד, בפריים ברזולוציה מלאה שנשלף מחדש
מהווידאו. השלב השני הוא מה שמסנן טעויות של השלב הראשון (`--no-confirm` מבטל).

העלות נגזרת ממספר הפריימים: `--max-frames` (ברירת מחדל 400) דוגם באופן אחיד
מתוך מה שסיננת, ו‑`--dry-run` מדפיס את התוכנית בלי לקרוא ל‑API בכלל. כדאי
לצמצם קודם עם `--video`, `--from/--to` ו‑`--min-activity`.

המודל הוא `claude-opus-5`. שלב המיון רץ ב‑`--effort low` (זו הכרעה ויזואלית
פשוטה) והאימות ב‑effort גבוה.

## כוונון

| התופעה | מה משנים |
|---|---|
| לא מוצא אדם שרואים אותו בבירור | להוריד `--threshold` (0.363 ← 0.30), להוסיף תמונות ייחוס, `--fps` גבוה יותר |
| מזהה את האדם הלא נכון | להעלות `--threshold` (0.363 ← 0.45), תמונות ייחוס חדות יותר, `--min-sharpness 20` |
| האינדוקס איטי | להוריד `--fps`, לוותר על `--objects`, להוריד `--width` |
| מסנן התנועה מדלג על אירועים | להוריד `--motion` (0.004 ← 0.001) או `--motion 0` לביטול |
| לא מזוהות פנים בכלל | המצלמה רחוקה או גבוהה מדי; לנסות `--width 1920` ולבדוק ב‑`vscan videos` |

מדידה על 4 ליבות CPU, מקור 1080p, דגימה של 2 פריימים בשנייה, בלי מסנן תנועה:
**פי ~13 מזמן אמת** עם זיהוי פנים בלבד, **פי ~3** גם עם `--objects`. בפועל
מסנן התנועה מדלג על רוב הפריימים בהקלטת אבטחה אמיתית, כך שהמהירות גבוהה
בהרבה. שעת הקלטה בדגימה של 2 fps תופסת בערך 50–150MB של תמונות ממוזערות;
`--no-thumbs` מבטל אותן (במחיר `ask` ותמונות בדוחות).

הציון בזיהוי פנים הוא דמיון קוסינוס בין וקטורי SFace; 0.363 הוא הסף הרשמי של
OpenCV ל"אותו אדם", וזו ברירת המחדל.

## מגבלות שכדאי להכיר

- זיהוי פנים דורש פנים ברוחב 24 פיקסלים לפחות. אדם שמצולם מגבו, מלמעלה או
  בחושך יימצא דרך `objects`/`ask`, לא דרך `find`.
- דיוק הזמנים הוא כמרווח דגימה אחד (חצי שנייה ב‑2 fps). הקטעים עצמם נחתכים
  מהקובץ המקורי ולכן מדויקים.
- הקיבוץ הוא חמדני וחד־מעברי: אותו אדם בתאורה שונה מאוד עלול להתפצל לשני
  אשכולות. אפשר לתת שם לשניהם — הם מתמזגים לזהות אחת.
- `ask` רואה רק את הפריימים שנשלחו אליו: הוא לא עוקב בין פריימים, ומונחה
  במפורש לא לנחש זהויות של אנשים.

## לפני שמשתמשים

זיהוי פנים של אנשים אמיתיים מוסדר בחוק כמעט בכל מקום (בישראל — חוק הגנת
הפרטיות ועמדות רשות הגנת הפרטיות בנוגע למאגרים ביומטריים; באירופה GDPR סעיף
9). כדאי להריץ את זה רק על הקלטות שמותר לך לעבד, למטרה שאתה יכול לנסח, לשמור
את האינדקס רק כל עוד הוא נחוץ (`vscan-index/` מכיל חיתוכי פנים ווקטורים
ביומטריים — זהו מידע אישי), ולשלט את האזור שבו מצלמים כשהחוק דורש. הכלי לא
מחליט את זה במקומך.
